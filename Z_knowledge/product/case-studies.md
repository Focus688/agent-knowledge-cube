# Z: Customer Case Studies Library

## 成功案例模板 / Case Study Template

```
# [Customer Name] — [Industry Vertical]

## 概述 / Overview
- Company size: [Employees / Revenue]
- Use case: [What they use the product for]
- Previous solution: [What they migrated from]

## 挑战 / Challenge
[The problem they faced — quantified if possible]

## 解决方案 / Solution
[How they implemented our product — deployment details]

## 成果 / Results (with metrics)
- Metric 1: Before → After (e.g., 40h/week → 8h/week)
- Metric 2: % improvement
- Metric 3: ROI / cost savings
- Timeline: [Time to value]

## 客户评价 / Customer Quote
> "[Quote about the product experience]"
> — [Name, Title]

## 资产 / Assets
- Screenshots / demo video link
- Logo file
- Permission: [Public / Internal only / Anonymized]
```

## 行业垂直 / Industry Verticals
- SaaS / Technology
- Financial Services / Fintech
- Healthcare / Life Sciences
- E-commerce / Retail
- Education / EdTech
- Manufacturing / Logistics

## 最佳实践 / Best Practices
- Always lead with **quantified results** (X% faster, Y hours saved)
- Include **before/state** to show contrast
- Get **written approval** before publishing
- Update case studies annually with latest metrics
