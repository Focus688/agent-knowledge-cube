# Z: Product Roadmap Template

## 时间维度 / Time Horizons

| Horizon | Timeframe | Confidence |
|---------|-----------|------------|
| **Now** | Current quarter | 90% — committed, resourced |
| **Next** | Next quarter | 60% — likely, rough sizing |
| **Later** | 2+ quarters out | 30% — directional, may change |

## Theme Grouping
- Group initiatives by **outcome** (not features)
  - *"Grow activation"* > *"Build onboarding wizard"*
  - *"Reduce churn"* > *"Add notification preferences"*
- Each theme gets a single metric target

## 优先级框架 / Priority Framework

### RICE Score
- **R**each — how many users affected per quarter
- **I**mpact — impact magnitude (0.25x, 0.5x, 1x, 2x, 3x)
- **C**onfidence — certainty of estimates (20%, 50%, 80%, 100%)
- **E**ffort — person-weeks required
- Score = (Reach × Impact × Confidence) / Effort

### ICE Score (faster, less precise)
- **I**mpact, **C**onfidence, **E**ase — each scored 1-10

## Dependency Tracking
- `D-001: Feature X depends on API v2 launch (Eng team, Q2)`
- Critical path → milestones → cross-team synchronization

## Stakeholder Communication
- **Weekly**: status update (on-track / at-risk / blocked)
- **Monthly**: roadmap review with leadership
- **Quarterly**: full roadmap refresh + retrospective
