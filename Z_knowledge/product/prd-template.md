# Z: 产品需求文档模板
# 知识域 — 产品类

## PRD 结构

### 1. 背景与目标
- 问题陈述
- 用户痛点
- 业务目标（量化）
- 成功指标

### 2. 范围
- **包含**: 明确的功能列表
- **不包含**: 明确排除的功能
- **MVP 定义**: 最小可发布功能集

### 3. 用户故事
```
As a <角色>
I want <功能>
So that <价值>

验收条件:
- Given <前提> When <操作> Then <结果>
```

### 4. 交互流程
- 正常流程
- 异常流程
- 边界情况

### 5. 数据需求
- 新增数据字段
- 数据迁移要求
- 报表需求

### 6. 技术约束
- 性能要求
- 安全要求
- 兼容性要求

### 7. 发布计划
- 阶段划分
- 里程碑
- 风险与依赖
