# Z: 产品演示脚本

## Demo 标准化流程

### 1. 开场 (5分钟)
- 了解客户背景和目前方案
- 确认本次演示关注点
- 设定议程

### 2. 痛点映射 (10分钟)
- "刚才您提到 [痛点]，我们来看下如何解决"
- 演示与客户场景直接相关的功能
- 对比客户现有方案的操作流程

### 3. 价值展示 (15分钟)
- 核心工作流完整走一遍
- 强调差异化功能
- 展示实际案例数据

### 4. 竞品差异 (5分钟)
```
[产品名] vs [竞品]
- 为什么我们在 [功能] 上更好
- 什么场景下选择我们最合适
- 迁移成本如何最低
```

### 5. Next Steps (5分钟)
- 问题解答
- 是否满足需求
- 下一步: PoC / 试用 / 报价
- 确认时间线和决策流程

## 常见反对意见应对
- "太贵了" → 价值对比 / TCO 分析
- "再看看" → 现在行动的优势 / 限时优惠
- "需要内部讨论" → 提供决策材料 / 协助内部present
