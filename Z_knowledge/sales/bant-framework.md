# Z: BANT 框架

## Budget 预算
```
"这个项目有预留预算吗？大概范围多少？"
"除了软件许可证，还考虑了实施和培训成本吗？"
"预算决策流程是怎样的？"
```

## Authority 权限
```
"除了您，还有谁参与选型决策？"
"如果方案合适，您是否可以推给决策者？"
"之前有做过类似的采购吗？流程是怎样的？"
```

## Need 需求
```
"目前是怎么处理这个问题的？"
"您希望新方案解决什么具体问题？"
"如果不解决会有什么影响？"
```

## Timeline 时间线
```
"希望什么时候上线？"
"启动计划是怎样的？有里程碑吗？"
"是什么触发了现在要考虑这个？"
```
