# Z: SEO 关键词策略

## 关键词研究流程
1. **种子词** — 核心业务相关词 (如 "项目管理软件")
2. **扩展** — 长尾词, 问题词, 竞品词
3. **聚类** — 按搜索意图分组 (信息/导航/交易)
4. **优先级** — 搜索量 × 难度 × 相关性

## 关键词层级
| 层级 | 类型 | 频率 | 优化目标 |
|------|------|------|---------|
| Tier 1 | 核心词 (2-3词) | 高流量 | 首页/落地页 |
| Tier 2 | 主题词 (3-4词) | 中流量 | 栏目页/专题 |
| Tier 3 | 长尾词 (5+词) | 低流量高转化 | 博客/FAQ |

## 技术 SEO 检查清单
- [ ] 页面 title 唯一且含关键词
- [ ] meta description 150-160字符
- [ ] 结构化数据 (JSON-LD)
- [ ] Core Web Vitals 达标
- [ ] 移动端适配
- [ ] 内部链接结构合理
- [ ] XML sitemap 更新
- [ ] robots.txt 配置正确
