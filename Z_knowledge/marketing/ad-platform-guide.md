# Z: 广告平台操作指南

## Google Ads
- **格式**: 响应式搜索广告 (RSA), 自适应展示广告
- **出价**: 目标 CPA / 最大化转化 / 目标 ROAS
- **受众**: 有购买意向 / 类似受众 / 再营销
- **素材要求**: 标题 30字符×15, 描述 90字符×4

## LinkedIn Ads
- **格式**: 单图广告 / 视频广告 / 对话广告 / InMail
- **定向**: 职位 / 公司 / 行业 / 技能 / 资历
- **出价**: CPC / CPM / 目标 CPL
- **素材**: 1200×627px, 简洁标题+强 CTA

## 微信广告 (朋友圈/公众号)
- **格式**: 外层素材 + 落地页 / 小程序 / 关注
- **定向**: 地域 / 年龄 / 兴趣 / 设备
- **出价**: CPM / OCPM (优化出价)
- **审核**: 提前 2 个工作日提交素材
