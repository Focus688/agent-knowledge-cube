# Z: 产品发布公告计划

## 公告渠道优先级
1. 产品内公告 (Banner/Modal)
2. 官方邮件列表
3. 公众号/社交媒体
4. 博客文章
5. 媒体新闻稿 (重大发布)

## 公告时间线
```
T-7天: 内部培训材料准备
      客服/销售 FAQ 初稿
T-3天: 给大客户/内测用户提前通知
T-1天: 所有素材就位，最终审核
T-0:  发布公告，通知客服/销售上线
T+1:  监控反馈，发布 FAQ 补充
T+7:  收集数据，复盘
```

## 公告内容模板
```
标题: [产品名] [版本号] 正式发布 — [核心价值]
摘要: 一句话说明
亮点: 3-5个核心功能
影响: 对用户/客户的价值
指引: 升级/使用指引
链接: 文档/演示/FAQ
```
