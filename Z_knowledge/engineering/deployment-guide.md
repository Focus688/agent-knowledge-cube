# Z: 部署指南
# 知识域 — 工程类

## 部署前检查
1. 数据库迁移脚本已创建并测试
2. 配置项已更新（环境变量、Feature Flags）
3. 回滚计划已准备
4. 监控告警已配置
5. 发布说明已撰写

## 部署流程
```
1. 创建 Release Branch
2. CI 运行完整测试套件
3. 构建 Docker 镜像
4. 推送镜像到 Registry
5. 更新 K8s Deployment
6. 灰度发布（10% → 50% → 100%）
7. 健康检查确认
8. 标记上线完成
```

## 回滚流程
```
1. kubectl rollout undo deployment/<name>
2. 确认旧版本运行正常
3. 通知相关方
4. 定位问题原因
```

## 监控指标
- P50/P95/P99 响应延迟 < 200ms
- 错误率 < 0.1%
- Pod CPU/Memory < 80%
- 数据库连接池使用率 < 70%
