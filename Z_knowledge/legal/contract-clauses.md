# Z: 标准合同条款库

## 保密条款
```
双方应对本合同内容及履行过程中获知的对方商业秘密
承担保密义务，保密期限为合同终止后___年。
未经对方书面同意，不得向第三方披露。
```

## 责任限制
```
任何一方在本合同项下的累计赔偿责任上限为
合同总金额的___%。本限制不适用于故意违约、
重大过失、侵犯知识产权或数据泄露。
```

## 数据处理 (DPA)
```
处理方应采取适当的技术和组织措施保护个人数据，
包括但不限于：加密、访问控制、定期备份。
处理方应协助数据控制方履行其数据主体权利请求。
```

## 终止条款
```
任一方可提前___天书面通知终止本合同。
一方严重违约经___天宽限期未纠正的，
另一方有权立即终止合同。
终止后___天内，处理方应按要求删除或返还客户数据。
```

## 模板使用说明
- `___` 处填入具体数值
- 最终条款需经法务审批
- 跨国合同需确认管辖法律
