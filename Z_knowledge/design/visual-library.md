# Z: 视觉素材库目录

## 图标
- **风格**: 线性 + 面性双版本, 24x24px 基准
- **格式**: SVG sprite + React 组件
- **分类**: 导航/操作/数据/文件/社交/品牌
- **来源**: Phosphor Icons (开源) + 自定义品牌图标

## 插画
- **风格**: 扁平 + 渐变, 角色风格统一
- **分辨率**: 2x (@2x Retina 适配)
- **场景**: 空状态 / 欢迎页 / 错误页 / 营销素材

## 摄影
- **风格**: 真实场景, 暖色调, 有呼吸感
- **许可**: 自有拍摄 / Shutterstock / Unsplash
- **裁剪**: 16:9 主图 / 4:3 卡片 / 1:1 头像

## 品牌资产
- Logo: 横版/竖版/图标 三形态, 深色/浅色版本
- 品牌纹样: SVG 可循环图案
- 品牌字体: Inter + 授权字体
