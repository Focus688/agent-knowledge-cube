# Z: 设计规范交付标准

## Figma 文件结构
```
项目名称/
├── 01-发现/          # 用户研究、竞品分析
├── 02-定义/          # 信息架构、用户流程
├── 03-设计/          # 页面设计、组件
├── 04-原型/          # 交互原型、动效
└── 05-交付/          # 切图、标注、specs
```

## 组件命名规范
`[类别]/[组件名]/[状态]`
- `Button/Primary/Default`
- `Card/Product/Hover`
- `Input/Text/Focused`

## 开发者交接清单
- [ ] 设计稿标注完成（间距、颜色、字体）
- [ ] 切图导出（@1x/@2x/@3x, SVG优先）
- [ ] 动效参数说明（时长、缓动函数）
- [ ] 响应式断点适配方案
- [ ] 空状态/加载态/错误态/边界态
- [ ] 交互逻辑说明文档
