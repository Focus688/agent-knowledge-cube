# Z: 视觉设计指南

## 品牌色调
| Token | 色值 | 用途 |
|-------|------|------|
| --color-primary | #2563EB | 主按钮、链接、强调 |
| --color-secondary | #7C3AED | 二级品牌色 |
| --color-success | #10B981 | 成功状态 |
| --color-warning | #F59E0B | 警告状态 |
| --color-error | #EF4444 | 错误状态 |

## 字体系统
- **主字体**：Inter (无衬线), 14px 基础字号
- **代码字体**：JetBrains Mono, 13px
- **行高**：正文 1.5, 标题 1.2

## 间距网格
`4px` 递增：`4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80`

## 阴影层级
- 卡片：`0 1px 3px rgba(0,0,0,0.12)`
- 弹窗：`0 20px 60px rgba(0,0,0,0.3)`
- 通知：`0 4px 12px rgba(0,0,0,0.15)`
