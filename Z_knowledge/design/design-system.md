# Z: 设计系统

设计系统是产品和品牌一致性的基石，包含组件库、使用规范、主题系统和可访问性标准。

## 组件层级
- **基础原子**：颜色、字体、间距、图标
- **复合组件**：按钮、输入框、卡片、弹窗
- **业务组件**：用户卡片、数据表格、图表模板
- **页面布局**：标准布局、仪表盘、移动端

## 设计规范
- **色彩系统**：主色/辅色/中性色/语义色（成功/警告/错误/信息）
- **字体层级**：H1-H6, Body, Caption, 行距1.5倍
- **间距**：4px 网格系统，8/16/24/32/48/64
- **圆角**：4px 基础 / 8px 卡片 / 16px 弹窗 / 全圆角按钮

## 可访问性 (WCAG 2.1 AA)
- 色彩对比度 ≥ 4.5:1（正文）/ ≥ 3:1（大文本）
- 所有交互元素支持键盘导航
- 屏幕阅读器标签 (aria-label)
- 焦点状态清晰可见
