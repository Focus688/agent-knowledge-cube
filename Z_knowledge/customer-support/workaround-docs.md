# Z: 替代方案文档

## 已知限制替代方案

### 批量操作限制
- **问题**: UI 上限为 500 行
- **替代方案**: 使用 API 批量接口，无行数限制
- **风险**: 无

### 数据导出格式
- **问题**: 不支持 PDF 导出，仅 CSV/XLSX
- **替代方案**: 使用浏览器打印 → 保存为 PDF
- **风险**: 大量数据时可能截断

### 实时协作
- **问题**: 多人同时编辑同一数据有冲突风险
- **替代方案**: 使用"锁定"功能，编辑前锁定行
- **风险**: 如不锁定可能覆盖
