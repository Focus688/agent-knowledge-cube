# Z: 跟进模板

## 问题解决后跟进 (24h)
```
您好 [客户名]，
关于您之前提到的 [问题]，想确认一下是否已顺利解决？
如果还需要任何帮助，随时联系我们。
[客服签名]
```

## 满意度调查 (72h)
```
您好 [客户名]，
感谢您联系 [产品名] 客服。能否花 30 秒评价一下这次体验？
[评分链接: 1-5分]
您的反馈是我们改进的动力。
[客服签名]
```

## 工单重新开启
```
如果问题再次出现，可以直接回复此邮件，工单会自动重新开启。
或者登录控制台，在"我的工单"中查看历史记录。
```

## 定期跟进 (长期未解决的)
```
您好 [客户名]，
关于 [问题/需求]，这边有新的进展通知您：[更新内容]
是否需要约个时间沟通一下详情？
[客服签名]
```
