# Z: 客服知识库

## 知识库层级
```
知识库/
├── 产品文档/       # 功能说明、使用指南、版本更新
├── 故障排查/       # 常见错误、诊断步骤、解决方案
├── 流程SOP/        # 工单处理、升级流程、退款流程
├── 培训材料/       # 新人培训、产品更新培训
└── 参考资料/       # 行业术语、竞品对比、FAQ
```

## 文章质量要求
- 标题: `[问题类型] + 一句话描述`
- 结构: 问题描述 → 适用版本 → 解决步骤 → 预期结果
- 标签: 至少 3 个搜索标签
- 审校: 技术审核 + 内容审核 双层机制

## 维护流程
- 月度: 根据新工单更新知识库
- 季度: 完整审校，移除过时内容
- 即时: 产品发布/变更时同步更新
