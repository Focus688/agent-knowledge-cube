# Z: 解决方案模板

## 登录问题
```
1. 清除浏览器缓存和 Cookie
2. 尝试隐私/无痕模式
3. 确认密码正确（可重置密码）
4. 如使用 SSO，确认 SSO 服务正常
5. 如以上均无效，提供以下信息:
   - 浏览器版本
   - 错误截图
   - 是否有报错信息
```

## 数据不一致
```
1. 确认数据源是否同步正常
2. 手动同步触发: 设置 > 数据源 > 立即同步
3. 等待 30 秒后刷新页面
4. 如仍不一致，检查数据权限设置
```

## 性能问题
```
1. 确认网络连接正常 (ping api.xxx.com)
2. 关闭不常用的浏览器标签
3. 尝试切换网络 (WiFi → 热点)
4. 如持续卡顿，提供:
   - 操作步骤录屏
   - 浏览器 DevTools Console 截图
```
