# Z: 客户上线指南

## 上线流程
```
Day 1:   Kickoff 会议
         双方团队介绍, 项目目标对齐, 时间线确认
Day 3:   基础配置
         账户创建, 权限配置, SSO 集成
Day 7:   数据迁移
         数据导入, 格式校验, 历史数据迁移
Day 14:  培训
         管理端培训, 用户端培训, 管理员权限说明
Day 21:  试运行
         并行运行, 数据验证, 问题修复
Day 30:  正式上线
         老系统下线, 新系统全量切换
```

## 上线条目检查
- [ ] 客户对接人与角色已确认
- [ ] 初始配置已完成并验证
- [ ] 数据迁移完毕, 数据量已验证
- [ ] 核心用户培训完成
- [ ] 试运行期间工单数量在正常范围
- [ ] 客户确认可以上线
