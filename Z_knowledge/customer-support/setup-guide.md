# Z: 产品配置指南

## 初始设置
### 1. 账号创建
- 管理员账号: 建议使用公司邮箱
- 子账号: 通过 SSO 或邮件邀请
- 权限模板: Admin / Member / Viewer

### 2. 工作空间配置
- 工作空间名称、Logo
- 时区、货币、日期格式
- 默认语言 (中文/英文)

### 3. 集成配置
| 集成 | 配置方法 | 验证方式 |
|------|---------|---------|
| Slack | Workspace → 应用 → 授权 | 发送测试消息 |
| 飞书 | 开放平台 → 应用 → 权限 | 同步联系人 |
| GitHub | Settings → Developer → OAuth | 创建测试Issue |

### 4. 数据导入
- CSV 格式要求: UTF-8, 第一行表头
- 字段映射: 系统自动匹配, 人工确认
- 导入验证: 前 10 行预览 → 全量导入
