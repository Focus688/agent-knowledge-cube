# Z: 产品使用指南

## 快速上手
1. **注册/登录** — 支持邮箱/SSO/微信登录
2. **创建工作空间** — 团队名称 + 成员邀请
3. **第一个项目** — 创建项目 → 添加任务 → 设置截止日
4. **邀请团队** — 成员协作，分配权限

## 核心功能
- **仪表盘**: 个人/团队/项目 三级视图
- **任务管理**: 创建/分配/优先级/标签/附件
- **协作**: 评论区 @提及, 实时通知
- **报告**: 自动化周报, 进度追踪
- **集成**: Slack/飞书/企业微信/GitHub

## 快捷键
| Mac | Windows | 功能 |
|-----|---------|------|
| ⌘K | Ctrl+K | 全局搜索 |
| ⌘N | Ctrl+N | 快速创建 |
| ⌘/ | Ctrl+/ | 快捷键列表 |

## 常见操作
- 批量编辑: 多选任务后右键
- 模板: 项目模板 / 任务模板
- 筛选: 按状态/负责人/标签/优先级
